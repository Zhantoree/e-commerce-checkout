# Цели проекта
Главные цели проекта - углубленно освоить Backend на примере Nest JS и отточить навыки Frontend-а. 

## Основные задачи
- Поработать с ORM Prisma и SQL базами на псевдореальных кейсах, для лучшего понимания связей сущностей
- Реализовать полную авторизацию с http-only cookie на обоих фронтах backend/frontend
- Практика настройки CI/CD с нуля на свой сервер (возможен временный домен)
- Более углубленная практика написания тестов
- Подключение Stripe-оплаты с webhook-ми

## Что должно быть в MVP проекта?
- Авторизация юзеров с двумя ролями: покупатель (customer) и админ
- Страница каталога с фильтрами, сортировкой и поиском
- Отдельная страница для каждого товара с разными вариациями
- Страницы оформления:
    * Корзина (выбор и изменения товаров)
    * Доставка (тел., email, адрес и т.д.)
    * Оплата
    * Ревью и оформление заказа
    * Инфо после оплаты (чеки, подтверждение оплаты и т.д.)
- Полный автоматизированный CI/CD процесс от пуша на ветку до деплоя на сервер
- Покрытие тестами 80% **Backend** и **Frontend**

## Используемые технологии

### Backend
- Nest.js + Prisma ORM + Postgresql

### Frontend
- React + Next js (app router)
- Redux ToolKit
